Technical blogs have an awkward thumbnail problem: most posts don't have a
natural hero photo, and slapping stock art onto a post about a CLI tool or SQL
query planning feels wrong. On the other hand, a list of twenty titles and dates
with no visual anchor quickly turns into a wall of text.

To fix this, every post and project on this site gets a deterministic `64×64`
geometric badge (and a `640×140` header banner) compiled into static inline
`<svg>` markup during build time.

## How a seed becomes a glyph

Given a seed string like `"post:rebuilding-this-site"`, the generator runs two
tiny, zero-dependency stages:

1. **32-bit FNV-1a + MurmurHash3 finalizer (`hashSeed(seed)`):** Computes an
   FNV-1a hash over the UTF-16 code units and finishes with a 32-bit Murmur3
   avalanche mixer so even a single-character edit cascades across all 32 bits.
   Independent bit slices select:
   - **Motif family (`h0 % 10`):** Picks one of **10 geometric motif families** (`orbits`, `ridges`, `mesh`, `iso-stack`, `polar`, `lissajous`, `bus-routing`, `interference`, `hilbert`, or `automata`).
   - **Dual accent palette (`(h0 >>> 4) % 8`):** Picks primary and secondary
     technical accents from an 8-color HSL-balanced palette.
   - **Registration grid (`(h0 >>> 11) % 4`):** Selects between crosshair rings,
     octagonal target frames, axis ruler ticks, or corner brackets.
2. **SplitMix32 PRNG stream (`makeRng(h0)`):** Produces a repeatable stream of
   floats in `[0, 1)` from that 32-bit state to drive sub-topologies, orbital
   eccentricity, Fourier carrier frequencies, Lissajous ratios, and Hamiltonian
   lattice walks.

```ts
export function hashSeed(str: string): number {
  let h = 2166136261;
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  // MurmurHash3 32-bit finalizer for full bit avalanche
  h ^= h >>> 16;
  h = Math.imul(h, 0x85ebca6b);
  h ^= h >>> 13;
  h = Math.imul(h, 0xc2b2ae35);
  h ^= h >>> 16;
  return h >>> 0;
}
```

## Specimen gallery

Expanding from a handful of rigid templates to parameterized motif families—each
with internal sub-modes (e.g., coaxial vs. binary barycenter orbits, Gaussian vs.
bimodal Fourier envelopes, annular vs. phyllotaxis spiral meshes)—keeps
thumbnails visually distinct across long lists of posts.
