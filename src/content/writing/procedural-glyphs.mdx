Technical blogs have an awkward thumbnail problem: most posts don't have a
natural hero photo, and slapping stock art onto a post about a CLI tool or SQL
query planning feels wrong. On the other hand, a list of twenty titles and dates
with no visual anchor quickly turns into a wall of text.

To hopefully fix this, every post and project on this site gets a deterministic
`64x64` geometric badge (and a `640x140` header banner) compiled into static
inline `<svg>` markup during build time.

## How a seed becomes a glyph

Given a seed string like `"post:rebuilding-this-site"`, the build step runs two
tiny functions:

1. **32-bit FNV-1a hash (`hash(seed)`):** Picks one of **5 geometric motif
   families** (`variant = h0 % 5`) and one of **5 muted technical accent
   colors** (`(h0 >>> 3) % 5`).
2. **SplitMix32 PRNG stream (`makeRng(seed)`):** Produces a repeatable stream of
   floats in `[0, 1)` from that 32-bit state to drive orbital angles, wave
   frequencies, node coordinates, and layer rotations.

```ts
function hash(str: string): number {
  let h = 2166136261;
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return h >>> 0;
}
```

## The 5 procedural motif families

Below is a live build-time specimen grid generated from 18 different seed
strings across all five motif families (`v0` through `v4`):

export const seeds = [
  'post:rebuilding-this-site',
  'post:procedural-glyphs',
  'post:consensus-notes',
  'post:wal-compaction',
  'post:zero-copy-io',
  'post:raft-leases',
  'post:bloom-filters',
  'post:lsm-trees',
  'post:grpc-backpressure',
  'post:query-planner',
  'post:clock-drift',
  'post:ebpf-tracing',
  'post:tail-latency',
  'post:simd-parsing',
  'post:ring-buffers',
  'post:consistent-hashing',
  'post:merkle-trees',
  'post:b-plus-trees',
];

export function familyLabel(seed) {
  let h = 2166136261;
  for (let i = 0; i < seed.length; i++) {
    h ^= seed.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  const v = (h >>> 0) % 5;
  const names = ['v0 · orbits', 'v1 · ridges', 'v2 · mesh', 'v3 · iso-stack', 'v4 · polar'];
  return names[v];
}
